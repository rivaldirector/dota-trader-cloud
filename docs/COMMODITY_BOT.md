# Торговый робот по золоту и нефти

Модуль `commodities/` — робот, который генерирует торговые сигналы по золоту (GC=F)
и нефти (CL=F WTI, опционально BZ=F Brent) на данных Yahoo Finance (запасной
источник — Stooq, только дневные бары). Робот **не исполняет сделки** — он выдаёт
сигналы с точкой входа, стопом, целью и рекомендуемым объёмом; исполнение остаётся
за вами (или можно прикрутить брокерский API отдельно).

## Быстрый старт

```bash
pip install -r requirements.txt

# Разовый прогон: есть ли сейчас сигналы
python run_commodity_bot.py signals

# Бэктест стратегии на истории
python run_commodity_bot.py backtest --interval 1h --lookback 1y
python run_commodity_bot.py backtest --interval 1d --lookback 2y

# Live-режим: опрос рынка каждые 15 минут + уведомления
python run_commodity_bot.py live
```

## Стратегия

Тренд-следящая с входом на откате, симметричная для покупок и продаж:

1. **Фильтр тренда** — цена и EMA50 выше EMA200 → разрешены только покупки;
   ниже → только продажи. В боковике сигналов нет.
2. **Очки подтверждения** (0–5), сигнал при `score >= COMMODITY_MIN_SCORE` (по умолчанию 3):
   - EMA20 относительно EMA50 в сторону сделки;
   - свежее пересечение MACD с сигнальной линией (последние 3 бара);
   - RSI разворачивается после отката (BUY: из зоны ≤45, SELL: из зоны ≥55);
   - гистограмма MACD ускоряется 3 бара подряд;
   - отбой от полосы Боллинджера.
3. **Уровни по ATR(14)**: стоп = 1.5×ATR, цель = 3×ATR (R:R = 1:2).
4. **Объём** — из риска на сделку (по умолчанию 1% счёта): `объём = риск_в_$ / (1.5×ATR)`.

## Настройка (.env)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `COMMODITY_SYMBOLS` | `GC=F,CL=F` | тикеры Yahoo через запятую (можно добавить `BZ=F`, `SI=F`) |
| `COMMODITY_INTERVAL` | `1h` | таймфрейм: `15m`, `30m`, `1h`, `4h`, `1d` |
| `COMMODITY_LOOKBACK` | `6mo` | глубина истории для индикаторов |
| `COMMODITY_ACCOUNT` | `10000` | размер счёта для расчёта объёма |
| `COMMODITY_RISK_PCT` | `0.01` | риск на сделку (доля счёта) |
| `COMMODITY_ATR_STOP` | `1.5` | множитель ATR для стопа |
| `COMMODITY_ATR_TARGET` | `3.0` | множитель ATR для цели |
| `COMMODITY_MIN_SCORE` | `3` | порог силы сигнала (0–5) |
| `COMMODITY_POLL_SECONDS` | `900` | период опроса в live-режиме |
| `TELEGRAM_BOT_TOKEN` | — | токен бота от @BotFather (необязательно) |
| `TELEGRAM_CHAT_ID` | — | ваш chat_id для уведомлений |

Без Telegram-настроек сигналы печатаются в консоль. С ними — дублируются в чат.

## Пример сигнала

```
🟢 ПОКУПКА — Золото (COMEX) (GC=F)
Время бара: 2026-08-11 14:00 UTC
Вход:  2451.30
Стоп:  2440.80
Цель:  2472.30  (R:R = 1:2.0)
Сила сигнала: 4/5
Объём под риск 1.0% счёта: 9.52
Подтверждения: импульс EMA20/EMA50 в сторону сделки; свежее пересечение MACD; RSI разворачивается после отката; отбой от полосы Боллинджера
```

## Запуск как сервис (VPS)

```bash
nohup python run_commodity_bot.py live >> logs/commodity_bot.log 2>&1 &
```

Дедупликация сигналов хранится в `storage/commodity_signals.json` — при перезапуске
робот не шлёт повторно уже отправленные сигналы.

## Тесты

```bash
python -m pytest tests/test_commodities.py -q
```

## Важно

Это аналитический инструмент, а не инвестиционная рекомендация. Перед торговлей
реальными деньгами прогоните бэктест на нужном таймфрейме и поторгуйте сигналы
«на бумаге». Торговля фьючерсами и CFD связана с высоким риском.
